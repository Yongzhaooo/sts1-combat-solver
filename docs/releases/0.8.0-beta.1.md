## English

- Improved loop search and removed redundant plays from winning routes.
- Fixed search timeouts, progress display, Gremlin identification, card selection and several action-resolution issues.
- Added automatic opening Smoke Bomb escape with a default 15 HP threshold. An in-hand Reaper can heal before escape, with immediate Strength support. Entropic Brew considers freeing slots first; White Beast Statue encourages potion use when rewards are available.
- F6 now includes ordered plays, selections and hand order from the last five fights and the current fight.

Burning Pact mid-selection import and reselection ordering remain deferred.

Thanks to 七月流火（七月火）, ૭٩奶油糖果, 幼猫（浪花） and 严肃研究鸡煲打法中.
