# 0.8.0-beta.1

## 中文

本测试版接入 π_base v2.6 已验收的战斗搜索内核，优化循环状态分组，保留有限能量循环中的中间退出路线，并在找到胜线后尝试去掉多余动作。精简必须保持胜利、血量、成长、药水和受保护遗物计数，不能增加回合数。它有计算上限，不保证找到全局最短打法。

修复搜索轨迹失控、地精小队角色识别、选牌身份及部分动作结算问题。F6 诊断 JSON 默认附带本局最近五场战斗的玩家动作，无需另开测试模式；记录只留本机，导出后由玩家自行分享。

共用搜索流程从 Mod 后端拆出。Mod 负责设置、状态导入、执行、面板通信与诊断，搜索层负责搜索和胜线精简。Windows 与 macOS 使用同一 Python 文件清单，避免平台包漏掉求解依赖。冻结的 π 2.6 采集包保持原身份。

内核已有 96 个固定局面的验收，保留 75 场胜利。一条真实 Java 保存根的胜线从 28 步减至 26 步，战后 57 HP，14 路 RNG 与模拟终局一致。这些是内核回归证据，不代表整个 Mod 已完成实机长局测试，也不代表所有精简路线的后续 RNG 不变。

燃烧契约中途选牌导入和换选调序暂缓，待静默猎手求解器工作启动时重新评估。本版没有加入独立的烟雾弹、混沌药水或白象雕像新策略。

感谢七月流火（聊天昵称：七月火）、૭٩奶油糖果、幼猫（浪花）提供局面、出牌对照与异常反馈，感谢严肃研究鸡煲打法中提供选牌和循环思路。鸣谢按提供的聊天记录与截图署名。

## English

This beta adopts the validated π_base v2.6 combat search core. It speeds up loop-state grouping, preserves intermediate exits from finite-energy loops, and removes redundant actions after finding a winning route. Reduction must preserve victory, HP, permanent growth, potions and protected relic counters without adding turns. The bounded reducer does not guarantee the shortest possible route.

Fixes cover runaway search trajectories, Gremlin role identification, selection identity and several action-resolution cases. F6 diagnostic JSON now includes player actions from the last five fights in the current run by default. Records remain local until the player exports and shares them.

Shared search stages and plan reduction are separated from the Mod adapter. The adapter retains settings, state import, execution, messaging and diagnostics. Windows and macOS use one Python runtime inventory. Existing frozen π 2.6 collection packages keep their identities.

The core passed a fixed 96-position regression set with 75 wins retained. One saved Java replay was shortened from 28 to 26 actions, ending at 57 HP with all 14 RNG streams matching the simulated terminal state. This is core regression evidence, not a full live-game Mod evaluation. Reduced routes can change subsequent RNG.

Mid-selection import and reselection ordering for Burning Pact are deferred until work on the Silent solver. This beta does not include the separate Smoke Bomb, Entropic Brew or White Beast Statue policy changes.
